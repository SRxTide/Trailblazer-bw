准备事项

开始前先确认设备、账号和票务链接。准备好这些内容后，按页面步骤操作即可。

platform

Windows & Android

本教程面向 Windows & Android 安卓用户。请下载 Release 中的最新版（Win 压缩包或安卓 APK），无需任何开发环境。

account

B站账号

准备可扫码登录的哔哩哔哩 APP，并提前在会员购账号里维护好购票人信息。

ticket

票务链接

准备完整会员购页面 URL，例如 https://show.bilibili.com/platform/detail.html?id=123456。

小提示：如果某个票务需要在线选座，或账号里没有完整购票人信息，程序可能会提示暂不支持或获取失败。

下载与安装

运行程序只需要一个步骤：到 GitHub Release 下载最新版本，Windows 用户解压双击启动，Android 用户安装 APK 即可。

  1. 打开下载页面访问 Trailblazer-bw 最新 Release。请不要点绿色 Code 下载源码包。
  2. 下载对应版本在 Release 页面的 Assets 区域中，Windows 用户下载 .zip 压缩包，Android 用户下载 .apk 文件。
  3. 解压或安装Windows 用户将下载的压缩包解压到独立文件夹；Android 用户在手机上点击 .apk 开始安装。
  4. 启动程序Windows 用户双击解压文件夹里的 .exe 启动；Android 用户在手机桌面找到应用图标点击打开。
系统安全提示：首次运行或安装时如果系统弹出未知来源或安全提醒，请确认文件来自上面的 GitHub Release 页面后再选择继续安装/运行。

首次登录

首次运行或登录失效时，程序会让你扫码登录。按提示操作即可，不需要手动填写账号密码。

A

程序检查是否登录过

如果之前已经登录过且仍然有效，程序会直接进入菜单；如果没有登录过或登录失效，就会进入扫码登录。

B

使用 B站 APP 扫码

程序生成二维码后，用官方哔哩哔哩 APP 扫描并在手机端确认登录。若是安卓手机，可先将屏幕上的二维码截图保存，再在 B站 APP 的“扫一扫”中导入该截图。

C

选择下一步操作

登录成功后会看到 1. 配置抢票流程 和 2. 退出登陆。选择进入配置与执行流程。

填写票务信息

这是最重要的一步。程序会按顺序问你票务链接、想买哪一档、买几张、选择谁作为购票人、什么时候开始，以及是否需要结果通知。

  1. 输入票务网址粘贴 B站会员购票务详情页完整链接。链接一般长这样：https://show.bilibili.com/platform/detail.html?id=123456。
  2. 选择票务与数量从命令行列出的票档中输入序号，再输入购票数量。当前交互限制为 1-4 张。
  3. 选择购票人程序会读取账号下的购票人列表，并按票数逐个选择。已选择的购票人不会再次出现在后续可选列表中。
  4. 设置开始时间如果想等到开票前再开始，就填写北京时间；如果想马上开始，直接按回车留空。
  5. 设置结果通知如果你有 PushPlus，可以输入令牌接收通知；没有就直接回车跳过。
  6. 保存任务文件程序会自动保存一个任务文件，方便你下次直接选择使用，不需要重复填写。

执行流程

确认任务后，程序会检查信息、可选测试 PushPlus 推送，然后根据你填写的开始时间等待或立即执行。

01

检查任务

程序读取你选择的任务，显示项目、票档、购票人等摘要，方便最后确认。

02

等待开始时间

如果开始时间留空，程序立即开始；如果填写了时间，程序会按北京时间等待到指定时间。

03

执行任务

任务开始后请保持程序窗口打开。成功后会输出订单相关日志；如果填写了 PushPlus，也会发送通知。

常见问题

二维码登录失败怎么办？

确认网络可用，使用官方哔哩哔哩 APP 扫码，并在手机端完成确认。如果是安卓手机端运行，可以先把二维码截图保存，再在哔哩哔哩 APP 扫一扫中，选择相册导入该截图进行识别登录。若本地凭证已失效，可在程序菜单选择 2. 退出登陆 后重新扫码。

安卓（Android）端和 Windows 端的用法一样吗？

完全一样。在 Github Releases 中下载 .apk 安装包后直接安装启动，其内部操作步骤、填写的票务网址、抢票逻辑以及通知配置等流程与 Windows 版没有任何区别。

为什么获取不到票务信息？

先检查 URL 是否是完整会员购详情页链接；再确认票务仍处于可查询状态。若项目是选座票或缺少身份证、手机号购票人要求，当前流程会提示暂不支持。

为什么看不到以前保存的任务？

Windows 用户请回到你第一次解压程序的文件夹运行 exe；Android 安卓用户请确保未清除应用本地数据或卸载重装，任务配置默认保存在应用的私有数据目录中。

PushPlus 是必须填写的吗？

不是。PushPlus 只用于推送抢票结果通知。填写信息时直接回车留空即可跳过；填写令牌后，程序会询问是否发送测试消息。

使用注意

请仅在个人合规场景使用，遵守哔哩哔哩会员购规则和当地法律法规。黄牛、倒卖或其他违规用途不应使用本项目。

secret

程序运行生成的文件或私有缓存可能包含登录信息、购票人信息或推送令牌。不要发给陌生人，也不要上传到公开网站。
